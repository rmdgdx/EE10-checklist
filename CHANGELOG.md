# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] — 2026-09-05

### Fixed

- Repackaged the GitHub upload ZIP with `index.html` at the archive root
- Added repair instructions for repositories that display the README/theme page
- Clarified that `index.md` should be removed when it conflicts with `index.html`
- Emphasized uploading `.nojekyll` and selecting the `main` branch with `/ (root)`

## [1.0.0] — 2026-09-05

### Added

- Student profile fields for name, subject, and section
- Research entries for concept statement, variables, methodology, and data analytics
- 24-item proposal-quality checklist
- Ten-criterion, 100-point automated rating
- Quality bands and proposal-readiness interpretation
- Criterion-level evidence and status table
- Personalized strengths and prioritized revision recommendations
- Print and PDF-ready report layout
- Responsive royal-blue-and-gold interface
- Privacy-preserving offline operation
